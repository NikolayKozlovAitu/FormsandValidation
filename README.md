## Overview
This is Assignment #4 for the Front-End Development course focused on building, styling, and validating HTML web forms.

The project is split into three separate pages connected via a navigation bar:
* `index.html` (Part 1) — Basic contact form using native HTML5 validation attributes (`required`, `type`, `maxlength`).
* `part2.html` (Part 2) — Contact form styled with Bootstrap 5 components (`form-control`, `form-label`, placeholders).
* `part3.html` (Part 3) — User registration form designed with Bootstrap Grid layout, radio buttons, checkboxes, dropdown select, and reset functionality.

## Project Structure
* `index.html` — Part 1: Basic HTML Forms
* `part2.html` — Part 2: Bootstrap Forms
* `part3.html` — Part 3: Registration Form
* `README.md` — Project documentation and setup instructions
